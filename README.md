# AI AURA — Pocket Option OTC Edition

Read-only research and signal platform for Pocket Option OTC. It streams
live OTC market data, will generate BUY/SELL signals that the user executes
**manually**, records WIN/LOSS feedback, and learns in controlled, validated
batches.

**Hard constraints** (see docs/SECURITY.md, docs/ROADMAP.md):

- Never places trades — no order-execution code path exists in AI AURA, and
  a test suite guard (`tests/test_no_order_execution.py`) keeps it that way.
- No martingale / loss-chasing logic, ever.
- No profitability guarantees. The goal is to measure whether a
  statistically meaningful edge exists — honestly.
- The `PO_SSID` credential lives only in `.env` and is never logged,
  committed, or shared.

## Status

Phases 0–3 built (audit, provider, live stream tooling, raw storage) with 21
passing offline tests. The Phase-30 live validation gate is waiting for the
credential — see **Setup**.

## Setup

1. Python 3.11+ (developed on 3.13). Create the environment:

   ```
   python -m venv .venv
   .venv/Scripts/pip install -r requirements.txt
   ```

2. Copy `.env.example` to `.env` and put your captured `PO_SSID` there
   (capture instructions are inside `.env.example`). **Never paste the SSID
   anywhere else.**

3. Run the offline tests:

   ```
   .venv/Scripts/python -m pytest tests/ -q
   ```

4. Run the first-milestone live validation (10 minutes, writes
   `docs/LIVE_OTC_VALIDATION.md`):

   ```
   .venv/Scripts/python scripts/validate_live_otc.py --minutes 10
   ```

5. Watch the live feed any time:

   ```
   .venv/Scripts/python scripts/live_monitor.py --asset EURUSD_otc
   ```

## Risk statement

This project uses an **unofficial** client with a personal session
credential against Pocket Option's private API; that may violate their terms
of service and can lead to session/account suspension. OTC prices are
generated by the broker. Binary options carry a high risk of loss. Nothing
here is financial advice.
